# SAFIZ — Real Estate Marketing Website

A static, responsive one-page website (HTML/CSS/JS, no build step).

## Run
Open `index.html` in a browser, or deploy the folder to any static host (GitHub Pages, Netlify, Vercel).

## Customize
- **Contact:** +92 315 1282583 · info@safiz.pk. WhatsApp number is set in `SETTINGS` at the top of `assets/js/main.js`.
- **Photos:** image URLs are CSS variables at the top of `assets/css/style.css` (`--img-hero`, `--img-villas`, ...). Replace them with your own, e.g. `url("../img/hero.jpg")`.
- **Project / service / article text:** `PROJECTS`, `SERVICES` and `INSIGHTS` in `assets/js/main.js`.

## What the buttons do
- Navigation links smooth-scroll to each section (active link highlights while scrolling).
- "Get a Free Consultation" / "Start Your Project" open a validated form; on submit the enquiry opens in WhatsApp.
- Service tiles, "View Project" and "Read Article" open detail pop-ups.
- WhatsApp buttons, email, map, social icons and back-to-top all work; mobile hamburger menu included.
